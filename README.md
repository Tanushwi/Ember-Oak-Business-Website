# ☕ Ember & Oak — Specialty Coffee Roastery Website

A premium, interactive business website designed for **Ember & Oak**, a fictional small-batch specialty coffee roastery based in Bandra West, Mumbai.

The website combines elegant typography, modern animations, interactive shopping experiences, and a live-style roastery dashboard to create an immersive digital brand experience.

## ✨ About the Project

Ember & Oak is a modern coffee roastery website concept built to demonstrate how a premium business can establish its online presence through thoughtful UI design, smooth interactions, and engaging user experiences.

The website showcases the brand's story, coffee blends, roasting process, subscription plans, customer testimonials, and an interactive shopping cart.

It features a sophisticated dark aesthetic with vibrant accent colors, animated elements, and responsive layouts.

## 🚀 Key Features

- **Premium UI Design:** Modern dark-themed interface with elegant typography and a refined visual identity.
- **Animated Preloader:** Custom loading screen with an animated progress indicator.
- **Interactive Navigation:** Fixed navigation bar, smooth scrolling, mobile menu, and scroll progress indicator.
- **Animated Hero Section:** Staggered text animations, glowing background elements, and subtle parallax effects.
- **Live Roastery Dashboard:** Dynamic-style dashboard featuring:
  - Live clock displaying IST.
  - Animated roast temperature graph.
  - Simulated order activity feed.
  - Daily orders and revenue counters.
  - Sales by city visualization.
  - Peak order hours.
  - Green bean inventory indicators.
- **Brand Story:** Dedicated section highlighting the roastery's background and journey.
- **Roasting Process:** Interactive presentation of the coffee production journey.
- **Coffee Collection:** Product showcase with interactive add-to-cart functionality.
- **Shopping Cart:** Dynamic cart drawer with quantity controls, item management, and subtotal calculation.
- **Subscription Plans:** Coffee subscription options with dedicated calls to action.
- **Customer Testimonials:** Automatically rotating testimonials with navigation dots.
- **FAQ Section:** Interactive accordion for frequently asked questions.
- **Responsive Design:** Layout optimized for desktop, tablet, and mobile devices.
- **Micro-interactions:** Custom cursor, magnetic buttons, hover effects, toast notifications, and scroll-triggered animations.
- **Accessibility Considerations:** Semantic HTML, accessible button labels, and reduced-motion support.

## 🎨 Design Highlights

- **Color Palette:** Deep black backgrounds, lime-green accents, warm orange highlights, and subtle violet tones.
- **Typography:** Instrument Serif for expressive headings and Inter for clean, readable body text.
- **Visual Style:** Minimalist, premium, modern, and editorial-inspired.
- **Animations:** Smooth transitions, floating background elements, animated counters, and interactive hover states.

## ⚙️ Run Locally

Follow these steps to run the project on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/tanushwi/Ember-Oak-Business-Website.git
```

**2. Navigate to the project directory**

```bash
cd Ember-Oak-Business-Website
```

**3. Open the website**

Open `index.html` directly in your browser.

Alternatively, use the Live Server extension in Visual Studio Code for local development.

No additional dependencies or installation commands are required.

## 📝 Important Notes

- The live dashboard uses simulated data and JavaScript-generated activity rather than a connected backend.
- The shopping cart supports client-side item management and quantity updates.
- The checkout interaction is a front-end demonstration and does not process real payments.
- The project is currently implemented as a frontend website without a backend database or payment gateway.
